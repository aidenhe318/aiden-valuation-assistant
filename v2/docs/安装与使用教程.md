# 一、这个分享包能做什么

aiden估值助手是一套本地飞机与发动机租赁估值项目。分享包同时包含技能定义和完整模型，不是只有一段提示词。安装后可以用自然语言运行租赁收益、资产估值、残值、航司信用分析，以及生成正式 Word 估值报告。

## 你不需要准备什么

不需要 GitHub 账户，不需要克隆仓库，也不需要执行 git push 或 git pull。

不需要理解 Python 代码；安装命令可由 WorkBuddy 执行。

不需要照搬制作者电脑目录；分享版技能按自身所在目录定位文件。

可以先在电脑终端运行下面的命令。如果能显示 Python 3.10、3.11、3.12 或更高版本，即满足要求。

python --version

# 三、方法一：在技能页面上传 ZIP

适合 WorkBuddy 已提供“上传技能”入口的情况。不需要先解压，也不要只上传 SKILL.md。

第 1 步｜打开技能管理

进入“专家·技能·连接器”或“技能”管理页。不同版本的菜单名称可能略有差异。

第 2 步｜选择上传技能

点击“添加技能”→“上传技能”，选择 aiden估值助手-WorkBuddy分享包.zip。

第 3 步｜确认识别结果

技能名称应显示为 aiden估值助手，内部标识为 aiden-valuation-assistant。若提示找不到 SKILL.md，通常是压缩包被重复嵌套；配套 ZIP 已按根目录直接包含 SKILL.md 制作。

第 4 步｜新建对话并首次调用

输入“用 aiden估值助手运行完整测算”。首次使用应自动执行 scripts/setup.py；若没有执行，可明确要求“先运行首次配置”。

第 5 步｜核对测试结果

配置成功的标志是实际输出 37 passed。只看到“文件已上传”不等于模型环境已经安装完成。

# 四、方法二：把 ZIP 发给 WorkBuddy

适合不知道技能管理入口在哪里的情况。把整个 ZIP 放进 WorkBuddy 对话框，再发送下面的完整口令。只发 ZIP、不作任何说明时，客户端未必会主动安装，因此建议始终附上口令。

## 推荐安装口令

请安装我发送的 aiden估值助手技能包。解压后确认 SKILL.md 位于技能根目录，将完整目录安装到 WorkBuddy 技能目录；不要只导入 SKILL.md，必须保留 src、config、data、tests、references 和 scripts。安装后在技能根目录运行 python scripts/setup.py，安装依赖并运行全量测试。只有测试通过才报告安装成功；如果失败，请给出完整错误。

## WorkBuddy 应该完成的事情

完整解压并安装技能目录，而不是把 ZIP 当普通附件阅读后就结束。

运行 python scripts/setup.py，在技能目录中创建 .venv。

安装 requirements.txt 中的依赖，然后运行全量测试。

报告 37 passed；失败时展示实际错误，不声称已经可用。

## 没有上传入口时的备用方式

把完整解压目录复制到用户级 .workbuddy/skills/aiden-valuation-assistant/，重启 WorkBuddy 或新建对话。Windows 用户级目录通常位于当前用户目录下。此方式仍需运行首次配置脚本。

可以直接点名“aiden估值助手”，减少与其他技能混淆。下表中的话可以直接复制到新对话。

## 首次调用的推荐口令

用 aiden估值助手运行完整测算。若尚未配置环境，先运行 python scripts/setup.py；测试通过后执行全部模块，并列出关键结果和输出文件。

测算完成后，结果通常写入技能目录的 outputs/。你可以继续要求 WorkBuddy 把关键表格直接展示在对话中，不必自己寻找 Excel 文件。

# 六、做一项发动机估值

如果目标是一台具体发动机，最好先提供资产身份、技术状态和租约信息。信息不足时仍可先做桌面估值，但应明确假设和待核资料，不能把演示拆分当成合同事实。

## 可直接复制的估值口令

用 aiden估值助手为这台发动机做独立桌面估值。请分别给出当前裸机市场价值、带租约 DCF 最高合理买价、租约到期残值和买贵判断。不要把裸机价值与带租约价值相加；MR 未拆分时做 0%／50%／100%敏感性。资料不足处单列假设，最后生成正式 Word 报告。

当前市场基准和重大维修报价需要另行核实。模型内默认参数适合演示与区间级校准，不应被当作某一台发动机的正式评估结论。

# 九、使用边界与分享注意事项

模型输出用于投资研究和交易讨论，不构成 ISTAT、IBA 或其他持证评估师的正式评估。

残值公开数据通常只支持区间级校准。重大维修、文件缺失或不利退租状态可能使价值突破区间下限。

裸机市场价值与带租约 DCF 必须分开；带租约 DCF 已包含租金和期末残值，不能重复相加。

分享包不需要 GitHub，也不要求接收者执行 git push 或 git pull。后续修改以接收者本地文件夹为准。

把真实项目资料加入分享包前，先检查合同、承租人信息、报价和个人信息是否允许对外分享。

SHA256SUMS.txt 可检查文件是否在传输后变化；PACKAGE_INFO.json 记录来源提交和测试基线。

## 建议的分享方式

直接发送 ZIP 文件，并同时发送 Word 教程。接收者只需阅读教程第三或第四节，选择一种安装方式。暂存目录、创建教程的脚本和本地 .venv 不需要对外分享。
